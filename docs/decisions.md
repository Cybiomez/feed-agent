# Журнал решений — feed-agent

Формат: дата — решение — почему. Сюда же осознанные упрощения и дыры с планом закрытия.

## 24-09-2026 — старт MVP

- **Провайдер модели по умолчанию — QWEN через OpenRouter.** OpenAI-совместимый API →
  абстракция провайдера тривиальна, позже DashScope/локальную/Claude подменяем одной
  строкой конфига. Один ключ, бесплатные qwen-модели, дёшево для потока заголовков.
  - *Упрощение/риск:* у бесплатного тира OpenRouter есть лимиты частоты, модели иногда
    снимают. Смягчение: id модели — в конфиге (`settings.toml`), заголовки оцениваем
    **пачкой** за один запрос, прогон 2–3×/день. План: при упоре в лимит — DashScope или
    вторая модель как fallback.
- **Ключ — вне репозитория.** Читается из `OPENROUTER_API_KEY`; в бою наполняется из
  Vaultwarden через брокер `secret` в EnvironmentFile systemd. В git/config — никогда.
- **Оценка пачкой, полный текст не гоняем.** На модель уходят только заголовок+описание.
  Полный текст сжимаем (выжимка) только у прошедших порог — экономия токенов и приватность.
- **Отбор смещён в полноту (§ТЗ 3).** При сомнении — оставлять. Порог мягкий, настраивается.
- **Дедупликация — по хешу** (url + нормализованный заголовок). Уже виденное не повторяем.
- **Доставка — только через `notify`** (шов L1 не дублируем): дайджест уходит пайпом в
  `~/.local/bin/notify`, формат HTML.
- **Хранилище — SQLite** (`data/feed.db`): таблицы `sources`, `items`, `scores`, `reactions`,
  `kv` (профиль-мета/состояние). Открытые форматы, переносимо (§25).
- **Заглушка-провайдер** (`providers/stub.py`) — эвристика по стоп-словам/интересам из
  профиля, чтобы гонять пайплайн без ключа/сети (сухой прогон и тесты). Не решение по
  качеству — только чтобы механизм ехал.

## Открытый остаток (решим по ходу калибровки)

- Частота прогонов, порог отбора, объём дайджеста — сейчас дефолты в `settings.example.toml`.
- Точный формат «профиля вкуса» и место хранения — старт файлом `config/profile.md`;
  реакции 👍/👎 и их подмешивание — этап 2.
- Эмбеддинги/векторный отбор — этап 3, только если промпт-профиля перестанет хватать (§26).
