# Профиль вкуса

Этот файл — «вкус» фильтра: что интересно, что мусор, примеры. Модель читает его целиком
как часть промпта. Правь свободно, своими словами. Главный принцип отбора: **при сомнении —
оставлять** (лучше пропустить лишнее, чем потерять нужное).

Скопировать в `profile.md` и заполнить под себя (`profile.md` в git не попадает).

## Интересно (пропускать)

- Инфраструктура, DevOps, самохостинг, сети, безопасность.
- ИИ/LLM: практика, инструменты, заметные релизы моделей.
- Финансы и экономика: значимые сдвиги, а не ежедневный шум котировок.
- Геополитика: крупные события, влияющие на технологии/рынки. Упор на интересы РФ, достижения ВС РФ, события вокруг горячих точек, аналитика боевых действий, принятых решений, проектов и пр. 

## Мусор (отсекать)

- Кликбейт, «шок», списки «10 лучших…», гороскопы, лайфстайл.
- Реклама, пресс-релизы без сути, накрутка, дешёвые слухи.
- Мелкие обновления приложений без значимости.

## Примеры (few-shot)

Пока нет. Можно лить все по фильтру. При минимальном сомнении - лучше пропустить, а уже по реакции в будущем потихоньку корректировать. 
Интересные ТГ каналы:
КБ, Прямой эфир, Мой Компьютер, Просто DevOps, Пекарня
